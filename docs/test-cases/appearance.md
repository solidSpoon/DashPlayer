# 外观

用例文件：`e2e/appearance-settings.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

这一页要认清默认值：主题默认是**浅色**（`appearance.theme` 写死在 schema 里，不跟随系统深色模式，
外观页也只有深色/浅色两个按钮）；字号默认**大**；语言默认**跟随系统**。默认值是判别的基准，
写反了用例会假通过，所以下面每条都先说清「从哪个值切到哪个值」。

## 切换主题

浅色 → 深色（01），以及切回浅色（05）。

- 该看到：界面立刻变深色，配置文件里 `appearance.theme` 变成 `dark`。
- 用例：**[SET-APP-01]** 切换主题后界面立即生效并写入配置
- 落盘断言：`appearance.theme`

## 重启应用后沿用上次的主题

主题是最典型的「重启还在吗」：光断言界面类名不够，因为启动时可能有兜底样式恰好是深色。

- 该看到：重启后启动即深色，且进外观页时「深色」按钮带选中态（选中态来自后端回读，才排得掉兜底假通过）。
- 用例：**[SET-APP-02]** 重启应用后沿用上次选择的主题
- 落盘断言：`appearance.theme`

## 切换界面字号

大 → 小（默认是大）。

- 该看到：切到「小」后重进页面选中态落在「小」，「大」不再选中。
- 用例：**[SET-APP-03]** 切换界面字号后写入配置，重进页面仍回显所选档位
- 落盘断言：`appearance.fontSize`

## 切换界面语言

跟随系统 → English。

- 该看到：整个界面按所选语言渲染（英文时标题是 Appearance），语言下拉停在 English。
- 用例：**[SET-APP-04]** 切换界面语言后写入配置，重进页面按所选语言渲染
- 落盘断言：`i18n.language`

## 主题切回默认的浅色

深色 → 浅色，这条反向路径是「切回默认值」这一类问题的关口：
如果写回默认值被当成「没改动」而跳过，界面会显示浅色、配置文件里却还是深色，用户下次启动就看到主题弹回深色。
字号「小 → 大」、语言「English → 跟随系统」走的是同一条写入路径，不重复铺。

- 该看到：切回浅色后配置文件真的被覆盖成 `light`；重启后是浅色，且外观页选中态在「浅色」上。
- 用例：**[SET-APP-05]** 主题从深色切回浅色同样落盘，重启后不回弹到深色
- 落盘断言：`appearance.theme`
- 只断言「重启后是浅色」不算数——默认值恰好也是浅色，必须配上写盘断言才闭合。
