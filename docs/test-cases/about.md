这一页只有版本号和入口，没有需要保存的东西。用例断言「页面里不存在任何输入控件」，
作为一条守卫：以后谁往这页加了没有保存链路的输入框，这条用例会先红。

- 该看到：版本号（页面唯一的动态内容）可见；`input`、`textarea`、`select` 数量为 0。
