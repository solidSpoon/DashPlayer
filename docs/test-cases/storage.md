# 存储管理

用例文件：`e2e/storage-settings.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

## 改媒体库路径

用户把媒体库路径改到另一个目录。用例会先把目标目录建好，不去依赖后端「目录不存在就顺手创建」的行为。

- 该看到：重进页面输入框回显新路径。
- 用例：**[SET-STO-01]** 改完媒体库路径后落盘，重进页面仍回显
- 落盘断言：`storage.path`

## 填一个写不进去的目录

把路径填到父目录没有写权限的位置。这是「页面上填了、实际没保存」最容易发生的一种：
保存失败必须让用户看见原因，而不是安静地什么都不做。

- 该看到：页面出现红色错误条写明「当前存储目录暂时无法访问」；配置文件里的旧值没被覆盖；重进页面显示旧路径。
- 用例：**[SET-STO-02]** 填了没有写权限的目录会显式报错，不落盘也不在页面上假装已保存
- 落盘断言：`storage.path` 保持旧值
