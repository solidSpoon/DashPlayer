# 快捷键

用例文件：`e2e/shortcut-settings.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

## 改一个功能的按键，以及恢复默认

用户在弹窗里给「单句重播」录了一个额外的按键，保存回表单；再点该行的「恢复默认」。

- 该看到：加键后配置变成 `r,y`；恢复默认后变回 `r`，界面也不再显示 Y。
- 用例：**[SET-SHT-01]** 改完单个快捷键后落盘，重进页面仍回显；恢复默认同样落盘
- 落盘断言：`shortcut.repeatSingleSentence`

## 清空某个功能的全部按键

清空「播放 / 暂停」的三个默认按键。快捷键允许空串，空串表示**显式解绑**，
必须真写进配置，而不能被当成「没填」跳过；同时别的功能不能被带回默认值。

- 该看到：配置里 `shortcut.playPause` 变成空串，该行显示未绑定；另一个功能刚改的键仍在。
- 用例：**[SET-SHT-02]** 清空某个功能的全部按键会落盘为空绑定，重进页面显示未绑定且不影响其它功能
- 落盘断言：`shortcut.playPause`（空串）、`shortcut.repeatSingleSentence`（`r,y`）

## 搜索框

搜索框只是列表过滤器，不是设置项——这一点要靠「重进页面后搜索框为空、配置里没有这个键」来固定住。

- 该看到：按功能名和按键名都能过滤，无结果时有空态；搜索内容不会被当成设置保存。
- 用例：**[SET-SHT-03]** 搜索框按功能名与按键过滤，且搜索内容不会被当成设置保存
- 落盘断言：`shortcut.searchQuery` 不存在

## 弹窗里改完按键立刻切到别的设置栏目

弹窗的「完成并保存」只是把改动交回整页表单，真正的写盘还是整页那一次防抖保存。
用户很容易点完就走。快捷键这一页更怕丢，因为整份表单是一起保存的——挂起的改动丢了，
会连带丢掉同一时刻其它行刚改的键。

- 该看到：切回来时该行的按键清单里还有刚录的 Y（来自后端回读）。
- 用例：**[SET-SHT-07]** 弹窗里改完按键立刻切到别的设置栏目，改动仍会落盘并在重进后回显
- 落盘断言：`shortcut.repeatSingleSentence`（`r,y`）
