# 服务与资源

用例文件：`e2e/service-resource-settings.spec.ts`（本页所有自动化用例都在这里）

规范与状态含义见 [README.md](./README.md)。

这一页把「用哪个模型干哪件事」都串在一起了：云端密钥与模型清单、识别方式、翻译风格、
词典补充方式、字幕翻译 / 词典查询 / 整句讲解各自指到哪个引擎或模型。链路最长，也最容易被
「改 A 页让 B 页失效」这类问题咬到。

## 填云端服务的密钥、接口地址与模型清单

- 该看到：重进页面后密钥、接口地址都回显，刚添加的模型行还在表格里。
- 用例：**[SET-SVC-01]** 云端服务填写的密钥、接口地址与模型清单会落盘，重进页面仍回显
- 落盘断言：`apiKeys.openAi.key`、`apiKeys.openAi.endpoint`、`models.openai.available`

## 「查看详情」里的识别方式、翻译风格与词典补充方式

这三项藏在「查看详情」里，展开后才能改。翻译风格切到「自定义」后，提示词输入框才变成可编辑。

- 该看到：重进页面展开详情，三项选择与自定义提示词都回显。
- 用例：**[SET-SVC-02]** 识别方式、翻译风格与词典补充方式改动会落盘，重进页面仍回显
- 落盘断言：`transcription.engine`、`features.openai.subtitleTranslationMode`、`features.openai.subtitleCustomStyle`、`providers.dictionary`

## 识别方式在两个档位之间往返切

同一个下拉先切到「兼容模式」再切回「硬件加速」。往返是必要的：只切一次的话，
「其实没写盘、只是界面停在最后一次点击」这种错也能过。

- 该看到：每次切换都落盘，重进页面回显最后一次选的档位。
- 用例：**[SET-SVC-03]** 识别方式在兼容模式与硬件加速之间往返切换都落盘，重进页面回显最后一次选择
- 落盘断言：`transcription.engine`

## 用「使用预设」选一个厂商

- 该看到：接口地址与 API 类型当场回填，重进页面仍是这一套。
- 用例：**[SET-SVC-04]** 使用厂商预设会回填接口地址与 API 类型并落盘，重进页面仍回显
- 落盘断言：`apiKeys.openAi.endpoint`、`apiKeys.openAi.apiFormat`
- 断言不从弹窗里写死厂商参数，而是现读预设卡片上的地址与类型，避免厂商参数一改用例就废。

## 删模型：新增的能删，被功能占用的不能删

这是这一页的失败路径。内置模型被「整句讲解」等功能占用时删除按钮应当禁用；
新加的模型没被占用，删掉后要真的从配置里消失，而不是只从界面表格里消失。

- 该看到：占用行的删除按钮禁用；新增行可删，删后配置里也没有了。
- 用例：**[SET-SVC-05]** 新增的模型可以删除，被功能占用的模型不能删除
- 落盘断言：`models.openai.available`

## 新增云端模型后把字幕翻译指过去

模型清单来自页面详情缓存，保存成功后缓存会立刻刷新，所以新模型不需要重进页面就能在上拉里选中。

- 该看到：下拉里能直接选到新模型；重进页面该功能仍指着它。
- 用例：**[SET-SVC-06]** 把字幕翻译指到新增的云端模型后，模型槽位落盘并回显
- 落盘断言：`models.openai.subtitleTranslation`

## 把功能切到本地资源包

本地资源包有它的限制和前置条件，页面必须说清，否则用户只会觉得「选了没用」。

- 该看到：字幕翻译切到「本地基础资源包」时提示「轻量翻译只支持翻译为中文」；
  词典查询切到「本地增强资源包」而资源还没下载时提示「所选资源还没下载，请先在上方下载本地基础资源包」。
- 用例：**[SET-SVC-07]** 字幕翻译切到本地基础资源包后引擎落盘，重进页面回显且提示只支持中文
- 用例：**[SET-SVC-08]** 词典查询切到本地增强资源包后引擎落盘，重进页面回显并提示资源未下载
- 落盘断言：`providers.subtitleTranslation`、`providers.dictionary`

## 整句讲解切到「禁用」

- 该看到：开关落盘为关闭，重进页面仍是禁用。
- 用例：**[SET-SVC-09]** 整句讲解切到禁用后开关落盘为关闭，重进页面仍回显禁用
- 落盘断言：`features.openai.enableSentenceLearning`

## 还没覆盖的场景

这一页的缺口集中在「跨字段/跨页的连带影响」，正是单看一个控件时看不出来的部分。

### 把功能从云端模型切走后，原模型能不能删

- 现状：占用是现算的（看引擎和开关），但「切走之后占用真的解除了、模型立刻可删」这条链没人验过。
- 编号：**[SET-SVC-10]**（未覆盖）

### 云端密钥跨重启

- 现状：现有用例只覆盖「重进页面」，没覆盖关掉应用再开——密钥走的是本地安全存储，值得单独验一次。
- 编号：**[SET-SVC-11]**（未覆盖）

### 密钥留空，但功能仍指向云端模型

- 现状：保存时不报错、等调用时才失败，还是保存时就拦住？规则没定。
- 编号：**[SET-SVC-12]**（未覆盖）

### 把模型列表删空后再保存偏好

- 现状：存在半份写入的风险——引擎先写、模型校验后失败，可能留下一个指向已删模型的配置。
- 编号：**[SET-SVC-13]**（未覆盖）

### 云端连通性测试

- 现状：要真实网络与密钥。
- 编号：**[SET-SVC-14]**（手动）

### 本地资源下载与测速

- 现状：要真实下载与磁盘。
- 编号：**[SET-SVC-15]**（手动）

### 清理缓存

- 现状：要真实文件系统与统计。
- 编号：**[SET-SVC-16]**（手动）
