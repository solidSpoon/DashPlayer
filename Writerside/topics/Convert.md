# 修复播放问题

部分视频在 DashPlayer 中可能出现无声、卡顿、黑屏等兼容性问题，通常是因为视频的编码格式不被播放器支持。播放器检测到这类问题时会主动提示您，您也可以直接在「修复播放问题」页面处理。

这个功能会把视频转换为浏览器可以直接播放的格式（`.html5.mp4`），转换后的文件生成在原视频的同目录下，原视频保持不变。

## 如何使用

1. 进入侧边栏的 <control>修复播放问题</control> 页面
2. 点击 <control>添加文件</control> 选择单个视频，或添加整个文件夹批量处理
3. 点击 <control>修复</control> 按钮，等待转换完成
4. 转换完成后打开生成的 `.html5.mp4` 文件即可正常播放

已添加的文件和文件夹可以随时从队列中删除。

## 什么情况下需要使用

- 播放时画面正常但没有声音
- 视频无法播放或频繁卡顿、黑屏
- 播放器弹出"建议前往转换页面转一下格式"的提示
