# 基础用法

## 如何播放视频

DashPlayer 支持常见的视频格式（`mp4`、`avi`、`mov`、`wmv`、`flv`、`webm` 等），也支持 `mp3`、`m4a` 等纯音频的播客精听，字幕格式支持 `srt`、`vtt` 和 `ass`。

- 使用 <control>打开文件</control> 按钮选择一个视频文件，可同时选中配套的字幕文件一起打开
- 使用 <control>打开文件夹</control> 按钮导入整个媒体文件夹，DashPlayer 会自动查找文件夹里的视频和字幕文件
- 如果视频无法正常播放（无声、卡顿、黑屏），请参考 [修复播放问题](Convert.md)

## 如何控制播放

### 通过鼠标/键盘快捷键控制播放

DashPlayer 默认快捷键如下：

| 功能 | 默认按键 |
|------|----------|
| 上一句 | `←` 或 `a` |
| 下一句 | `→` 或 `d` |
| 重复当前句（跳回句首重听） | `↓` 或 `s` |
| 暂停/播放 | `space`、`↑` 或 `w` |
| 单句循环重播开关 | `r` |
| 自动暂停（播完一句自动停） | `u` |
| 显示/隐藏英文字幕 | `e` |
| 显示/隐藏中文字幕 | `c` |
| 显示/隐藏双语字幕 | `b` |
| 显示/隐藏逐词字幕 | `l` |
| 切换主题 | `t` |
| 循环切换播放速度 | `p` |
| 当前句字幕开始时间提前 0.2 秒 | `z` |
| 当前句字幕开始时间延后 0.2 秒 | `x` |
| 当前句字幕结束时间提前 0.2 秒 | `n` |
| 当前句字幕结束时间延后 0.2 秒 | `m` |
| 清除字幕时间微调 | `v` |
| 打开 AI 对话（整句学习） | `?` 或 `/` |
| 收藏当前片段 | `Shift + L` |
| 打开/收起控制面板 | `Shift + P` |

所有快捷键都可以在设置中心修改，具体见 [配置快捷键](Config-Shortcut.md)。

### 通过控制面板控制播放

进入播放界面后，点击右下角的圆形按钮（或按 `Shift + P`）可以打开控制面板，面板里集中了常用播放设置：

- **字幕轨道**：切换显示英文字幕、机器/AI 翻译字幕，或视频字幕文件自带的中文翻译
- **单句重播 / 自动暂停**：精听常用开关
- **自动播放下一集**：文件夹播放模式下，当前视频结束后自动播放下一个视频
- **倍速播放**：勾选常用速度后，用 `p` 键即可在这些速度间循环切换
- **夜间模式、全屏模式**：适配不同的观看环境
- **播客模式**：播放纯音频文件时建议开启
