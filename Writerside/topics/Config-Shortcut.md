# 配置快捷键

DashPlayer 的所有快捷键都可以在设置中心自定义，进入 <control>设置中心</control> → <control>快捷键</control>页面即可修改。

![shortcut.png](shortcut.png)

## 快捷键分类

快捷键设置页面按功能分为四组：

- **播放与控制**：上一句/下一句跳转、播放暂停、单句重播、自动暂停等
- **字幕显示**：英文字幕、中文字幕、双语字幕与逐词字幕的显示切换
- **时间轴微调**：微调当前句字幕的起始与结束时间点
- **界面与工具**：呼出 AI 对话、收藏片段、切换主题、打开控制面板等

## 如何修改快捷键

<procedure title="修改快捷键" id="edit-shortcut">
<step>在快捷键列表中找到要修改的功能，点击<control>编辑快捷键</control>。</step>
<step>在弹出的录制窗口中点击录制区域激活按键监听。</step>
<step>直接按下你想绑定的按键组合，例如 <code>Shift + L</code>。</step>
<step>点击<control>添加此按键</control>，然后点击<control>完成并保存</control>。</step>
</procedure>

几点说明：

- **一个功能可以绑定多个按键**：重复录制并添加即可，例如"暂停/播放"默认同时绑定了 `space`、`↑` 和 `w`。
- **恢复默认**：每个功能的编辑窗口中都提供「恢复默认按键」按钮；列表上方也可以按功能搜索。
- 设置修改后会自动保存，立即生效，无需重启。

## 默认快捷键总览

| 功能 | 默认按键 |
|------|----------|
| 上一句 | `←` 或 `a` |
| 下一句 | `→` 或 `d` |
| 重复当前句（跳回句首重听） | `↓` 或 `s` |
| 播放 / 暂停 | `space`、`↑` 或 `w` |
| 单句循环重播开关 | `r` |
| 自动暂停 | `u` |
| 显示 / 隐藏英文字幕 | `e` |
| 显示 / 隐藏中文字幕 | `c` |
| 显示 / 隐藏双语字幕 | `b` |
| 显示 / 隐藏逐词字幕 | `l` |
| 切换主题 | `t` |
| 切换播放速度 | `p` |
| 字幕开始时间提前 / 延后 0.2 秒 | `z` / `x` |
| 字幕结束时间提前 / 延后 0.2 秒 | `n` / `m` |
| 重置字幕微调 | `v` |
| 打开 AI 对话 | `?` 或 `/` |
| 添加收藏片段 | `Shift + L` |
| 打开控制面板 | `Shift + P` |
