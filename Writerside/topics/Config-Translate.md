# 配置 AI 服务

DashPlayer 的 AI 功能需要配置服务后才能使用。部分功能开箱即用（内置本地模型），云端 AI 功能则需要配置 API 密钥。

## 功能概览

| 功能 | 说明 | 服务来源 |
|------|------|----------|
| **字幕翻译** | 将英文字幕翻译为中文（或其他风格） | OpenAI / 腾讯翻译 / 关闭 |
| **词典查询** | 鼠标悬停在单词上查看释义与例句 | OpenAI / 有道词典 / 关闭 |
| **整句学习** | 对字幕句子进行语法分析、短语解释等 | OpenAI（可开关） |
| **字幕转录** | 为没有字幕的视频自动生成字幕 | 内置本地 Parakeet 模型，无需配置 |
| **单词发音** | 单词与文本的语音朗读 | 内置本地 TTS 模型，无需配置 |

可以看到：

- **只需配置 OpenAI，即可覆盖全部云端 AI 功能**（字幕翻译、词典查询、整句学习），是最推荐的配置方式。
- 有道词典、腾讯翻译为可选配置，分别可以作为词典查询和字幕翻译的替代方案。
- 字幕转录和单词发音使用内置的本地模型，无需配置 API；模型下载入口在「服务凭据」页面的「英语字幕识别模型」和「英语语音朗读模型」区域，详见 [人工智能字幕](AI-Subtitles.md)。

## 配置步骤

1. 在设置中心的「服务凭据」页面，填写对应服务的 API 密钥
2. 在设置中心的「功能设置」页面，为每项功能选择服务来源（也可以选择"关闭"停用该功能）

详细的 API 申请步骤请参考各服务的配置文档：

- [配置 OpenAI 密钥](Config-OpenAI-API.md)（推荐）
- [配置有道云密钥](Config-YouDao-API.md)（可选）
- [配置腾讯云密钥](Config-Tencent-API.md)（可选）

## OpenAI 字幕翻译风格

在「功能设置」页面将字幕翻译的引擎选为 OpenAI 后，还可以选择字幕的输出风格：

- **中文直译**：将英文字幕翻译为中文（默认）
- **简化英文**：将字幕转换为更简单的英文表达
- **自定义**：输入自定义 Prompt，控制字幕输出的样式
