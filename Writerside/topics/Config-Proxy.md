# 网络代理

如果您使用代理访问网络（例如访问 OpenAI API 或下载本地模型时需要代理），可以在 <control>设置中心</control> → <control>网络代理</control>页面配置 DashPlayer 的联网方式。

## 代理模式

| 模式 | 说明 |
|------|------|
| **跟随系统**（默认） | 读取操作系统配置的代理 |
| **自定义** | 使用下方填写的代理地址 |
| **不使用** | 所有请求直连 |

## 代理地址

选择「自定义」模式后，填写代理服务器的地址，支持以下协议：

- `http://`
- `https://`
- `socks5://`

例如：`http://127.0.0.1:7890`。

## 直连规则

填写逗号分隔的域名/IP/CIDR 列表，命中的地址将不走代理，直接连接。例如：

```text
localhost,127.0.0.1
```

> 转录字幕等功能使用本地模型，不需要联网；需要联网的主要是 OpenAI 等云端 AI 接口和模型下载。
