# 配置 OpenAI 密钥

> 如果你不知道 OpenAI 是什么，可以参考 [OpenAI 官网](https://www.openai.com/)。
>
> 简而言之，OpenAI 提供了强大且实惠的人工智能 API，可以用来做各种有趣的事情。

OpenAI 是 DashPlayer 的核心 AI 服务，配置后即可使用以下全部云端 AI 功能：

- **字幕翻译** — 使用大语言模型将英文字幕翻译为中文，或转换为简化英文等风格
- **词典查询** — 鼠标悬停在单词上，通过 AI 获取详细释义与例句
- **整句学习** — 对字幕句子进行语法分析、短语解释等深度学习

字幕转录和单词发音由内置的本地模型提供，与 OpenAI 配置无关。

## 获取 API 密钥

OpenAI 官方接口在部分地区可能不便获取，您可以通过第三方中转服务来获取 API 密钥，通常价格更实惠：

- https://uniapi.ai/
- https://aihubmix.com/

注册充值后即可获得 API Key 和 Endpoint。

## 在 DashPlayer 中配置

1. 打开设置中心，进入「服务凭据」
2. 在 OpenAI 区域填写 **API Key** 和 **Endpoint**
3. 点击「测试连接」按钮验证配置是否正确

> DashPlayer 支持所有 OpenAI 兼容接口，仅使用 chat completion API 格式。
>
> {style="note"}

### 接口地址自动追加 /v1

「服务凭据」页面的 OpenAI 区域提供「是否自动追加 /v1」开关：

- **开启（默认）**：DashPlayer 会自动在接口地址后追加 `/v1`，直接填写服务商给你的域名即可
- **关闭**：请在 Endpoint 中自行包含 `/v1` 路径

## 配置可用模型

在服务凭据页面的 OpenAI 区域下方，您可以管理可用的模型列表：

1. 在输入框中填写模型名称（如 `gpt-4o-mini`），点击「添加」
2. 添加的模型会显示在模型表格中，并标注该模型正被哪些功能占用
3. 已被功能占用的模型不能删除；删除前请先在「功能设置」中为相关功能更换模型

<!-- 截图占位：模型管理表格 -->

## 为功能分配模型

进入设置中心的「功能设置」页面，可以为每项功能分别选择使用的模型：

- **字幕翻译** — 选择用于翻译字幕的模型
- **词典查询** — 选择用于单词释义的模型
- **整句学习** — 选择用于句子分析的模型

不同的模型在效果和价格上有所差异，您可以根据需求灵活选择。
